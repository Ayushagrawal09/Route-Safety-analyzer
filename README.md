# Women Safety Analysis and Safe Route Finder

Women Safety Analysis and Safe Route Finder is a Python-based data analysis and graph optimization project designed to support safer travel decisions for women in Nagpur, India. The project evaluates road safety across different time periods—day (5 AM–4 PM), evening (4 PM–7 PM), and night (7 PM–5 AM)—using parameters such as street lighting, crowd density, CCTV availability, police proximity, reported incidents, and road distance. Built using Python, Pandas, NumPy, Matplotlib, and Seaborn, it incorporates data cleaning and validation, place-name normalization using the Longest Common Subsequence (LCS) algorithm, time-slot standardization, and a weighted safety-scoring mechanism to classify roads as Unsafe, Okay, or Good. The system models locations and road connections as a graph and uses Dijkstra’s algorithm with configurable safety penalties to compare the shortest route against potentially safer alternatives, allowing detours of up to 50% when they reduce exposure to unsafe roads. It also provides safety rankings, area-level risk comparisons, statistical visualizations, and map-based route representations to make the analysis easier to interpret. The primary objective is to demonstrate how data-driven decision-making, graph algorithms, and exploratory data analysis can be applied to a real-world social challenge: helping women make more informed travel choices and highlighting areas where improvements in public safety infrastructure may be needed. This project is an analytical prototype based on the available dataset, not a real-time navigation or emergency-response system; its recommendations depend on the accuracy, completeness, and freshness of the underlying data.
